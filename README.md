# ScheduleI_LargerMoneyStacks
A money stack adjusting mod for the game [Schedule 1](https://store.steampowered.com/app/1284220/Schedule_1/).

## About
ScheduleI_LargerMoneyStacks increases the money stack maximum size from 1000 to 99,999. This also changes the right click functionality of money, changing the default value from 1000 to 99,999.

## Installation
- Install MelonLoader (https://melonwiki.xyz/#)
- Download the `LargerMoneyStacks.dll` file.
- Place the `LargerMoneyStacks.dll` file in the Mods folder in your Schedule 1 installation folder.
- The mod will automatically start with MelonLoader and will run in the background.
